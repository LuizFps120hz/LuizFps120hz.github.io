# luizfps120hz.github.io

Terminal-style portfolio. Astro 7 + Tailwind CSS v4 + TypeScript, fully static, deployed to GitHub Pages with GitHub Actions.

## Features
- Boot-sequence hero with ASCII banner, typewriter roles and a matrix-rain canvas
- About (neofetch-style), skills with animated level bars, tech tickers
- **Projects reel**: horizontal infinite marquee (pauses on hover); your public GitHub repos are merged in at build time
- Experience as a `git log` timeline
- Interactive fake shell (`help`, `projects`, `theme amber`, `sudo`…)
- Contact with scraper-resistant email + copy button
- 4 themes (green / amber / cyan / dracula) + CRT scanline toggle, saved in `localStorage`
- Respects `prefers-reduced-motion`; works without JS

## Security
- Strict **Content-Security-Policy** generated by Astro (`security.csp`) with SHA-256 hashes. No `unsafe-inline` and no `eval`.
- No third-party scripts, fonts, CDNs, cookies or analytics. Fonts are self-hosted.
- Dynamic text is written with `textContent` only (no `innerHTML`).
- The workflow runs with least-privilege permissions, uses `npm ci` and `npm audit`, and Dependabot is enabled.

## Edit content
Everything lives in [`src/data/profile.ts`](src/data/profile.ts). Lines marked `// TODO` are placeholders.
The ASCII banner is in `src/components/Hero.astro`. The social image is generated with `npm run og` (edit `scripts/og.mjs`).

## Develop
```bash
npm install
npm run dev       # http://localhost:4321
npm run build     # type-check + build to dist/
npm run preview
```
Requires Node ≥ 22.23.

## Publish (one time)
1. Create a **public** repo named exactly `LuizFps120hz.github.io`.
2. Push this folder to `main`.
3. In the repo, go to **Settings → Pages → Build and deployment → Source** and choose **GitHub Actions**.
4. Each push to `main` deploys the site, and it also rebuilds every Monday so the project list stays current. After that, turn on **Enforce HTTPS** in Settings → Pages.
